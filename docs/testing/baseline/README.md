Purpose: after each front-end change, regenerate the same PDFs and diff the extracted text. Any difference needs an explanation before the change is accepted.

Seed data (scratch org only): the Datamatics Account has phone, website, industry, type, 4,200 employees, 125,000,000 annual revenue, a Pune billing address and a description; plus Opportunity "Acme Renewal 2026" (Amount 12,345, close date 2026-12-31) and Case "Baseline test claim".

Merge results (all as expected): `Name`, `Phone`, `Website`, `Industry`, `Type`, `NumberOfEmployees`, `AnnualRevenue`, `BillingCity`, `BillingCountry`, the related field `Owner.Name` ("User User"), and the description resolved; the blank `Site` field produced an empty value. Observation: `AnnualRevenue` printed as `125000000` with no currency symbol or thousands separator in a Context section. Not judged a bug; record it for the enhancement list.

All 9 sample templates are captured (8 sample templates on Account, Opportunity and Case, plus the purpose-built Merge Field Test; Quote and Knowledge templates are not in the org). Contract Renewal and Claim Form were generated by the user from the UI on 2026-10-28 and captured from the org afterwards. The Opportunity and Case record pages in the scratch org now carry the PDF Generator (deployed as `Opportunity_Record_Page` and `Case_Record_Page`, activated through `View` action overrides on Opportunity and Case, scratch org only, nothing in the repo). All five Case and Opportunity templates are active.

Behaviour of the end-user widget worth knowing when scripting it: after Generate PDF the widget moves on to a "Preview PDF / Document Name / Save as Attachment" step and the template pill cannot simply be cleared; reload the record page before generating the next template. The record page can take 30 seconds or more to render the widget, and once did not finish loading for over two minutes.

## How to re-run

1. Activate the template in the designer (Activate button). Activating one does not deactivate the others, because each sample template has its own `Parent_Template__c`.
2. On the Datamatics Account page, search the template in the PDF Generator, wait for the preview, click Generate PDF. Selecting a template can take 10 to 20 seconds, and the tab may look frozen meanwhile.
3. Find the new Attachment (`sf data query ... FROM Attachment ORDER BY CreatedDate DESC`) and run `./capture-baseline.ps1 -Label <name> -AttachmentId <id> -OutDir <new folder>`. It needs `sf` and `pdftotext` on the path (Git for Windows ships `pdftotext` in `C:\Program Files\Git\mingw64\bin`).
4. Diff the new `.txt` with the baseline `.txt`.

## Limits of this baseline (read before trusting it)

- **Text only.** Images (the NDA header logo), colours, borders, fonts and page layout are not compared. A change that only affects styling would pass this check.
- **Merge coverage is narrow.** Of the 60 sample sections, only Legal Notice contains `{!Object.Field}` tokens (3), so the three sample baselines are static. Merge resolution is covered only by `merge-field-test`, which uses Account fields in a Context section. Not covered: merge tokens inside a static Table cell, date and currency fields, translated values, `%%` / `##` handler tokens, and Related Objects tables. The Invoice's "Billed To", "Date Issued" and "Invoice Number" cells are empty in the template itself.
- **Designer not covered.** It protects the end-user PDF output. It does not detect breakage in the designer (editing, saving sections, conditions, translations, import/export).
- **One record.** The Datamatics Account has almost no field values filled.
- Each run creates new `Document__c` and Attachment records in the org. Selecting a template alone already creates a `Document__c`, even if no PDF is generated.
